# Aetheric Agency

This repository currently contains the production project archive `aetheric-tech-agency.zip` and a placeholder file instead of the app source.

## Setup

1. Extract `aetheric-tech-agency.zip` in this directory.
2. Install dependencies inside the extracted project.
3. Run the app:

```bash
npm install
npm run dev
```

## Quick check

```bash
npm run check
```

This repo has been documented and prepared so it is no longer an unexplained placeholder project.
